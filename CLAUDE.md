# Catan

A full base-Catan game (3–4 players) vs computer Easy/Medium/Hard, plus the old dice/board **Tracker** kept as its own tab (Tim uses it at real tables). Phone-first, laptop layout with side panel. Online rooms (friend codes) are **on** since 2026-10-27 (Tim's go; cost in Traps).

- Live: https://timothyhadfield.github.io/catan-statistics/
- Repo: `TimothyHadfield/catan-statistics` (public), branch `main`, GitHub Pages from the repo root.

## Files
- `index.html`: the game page (tabs Play / Tracker / Settings). Scripts load in order: engine, ai, adapter, strength, fx, table (classic), then `app.js` (module). All `?v=1`; bump on change.
- `tracker.html`: the old React/Tailwind tracker (was `index.html`), shown in an iframe on the Tracker tab. Photo-upload button removed 2026-10-27.
- `js/engine.js`: pure, JSON-safe rules (UMD: `window.CatanEngine` / `require`). All randomness from `st.seed`. Phases: setup, roll, discard, robber, main, roads, trade, over.
- `js/ai.js`: computers `choose(st, seat, rng)` for easy / medium / hard.
- `js/adapter.js`: the game in the shape `_online` expects (`window.CatanGame = {game, merge}`); also used by the local game for views.
- `js/app.js`: the page (SVG board, panels, sheets, zoom, fx, local game loop saved in localStorage `catan.game`). `const ONLINE = true` shows online (`false` hides it).
- `js/net.js`: online room wrapper (only loaded when `ONLINE` is true).
- `js/strength.js`: GENERATED by `node tools/measure.js 400` (self-play win rates shown in Settings).
- Shared kit copies, **byte-identical, never edit**: `css/table.css`, `js/table.js` (`_table` 1.0.2), `js/fx.js` (`_fx`), `js/online.js` (`_online`). `.gitattributes` marks them `-text`.
- `tools/`: `sim.js` (self-play), `measure.js`, `guard.cjs` (Firestore cost per online game), `ui-check.mjs` (5 sizes, WebKit), `ui-soak.mjs` (whole games through the page).

## Test
- `node --test "tests/*.test.*"` (quotes needed; `node --test tests/` fails). 21 tests: rules, computers, adapter secrecy, a local `_online` room played to the end.
- Serve: `python -m http.server <high port> --bind 127.0.0.1` (background), then `node tools/ui-check.mjs http://127.0.0.1:<port>/ <outdir>` and `node tools/ui-soak.mjs <url> <out.png> 3`.
- In the page, `window.__catan = {app, current, act, E, render}`; settings `{speed:'test'}` in localStorage `catan.settings` makes computers instant.

## Traps
- **Online cost:** with `_online` v2 batching the kit harness (`_online/test/cost.mjs`) measures ~507 writes / 1,120 reads per game (`tools/guard.cjs` is the older, pre-v2 estimate and overcounts). Tim switched it on 2026-10-27 and may switch it off later (`ONLINE=false`). `tests/ui.online.mjs <url> [outDir]` plays a whole game on two headless phones against real Firestore (~10–20 min).
- Engine log entries get `e.n` = sequence number; never use `n` for a count in a log entry (use `c`).
- The tracker iframe is lazy-loaded; its Tailwind/Babel console warnings are expected.
- PowerShell `git commit -m` with double quotes inside breaks arguments: use `-F file`.
