# Catan Statistics Tracker

Track the dice across a game of Catan and see how the real rolls compare to the
theoretical distribution.

🔗 **Live:** https://timothyhadfield.github.io/catan-statistics/

## What it does

- **Dice tracker** — record each roll as it happens and watch the observed frequency of
  2–12 build up against the expected bell curve.
- **Probability distribution** — a live chart of how far the game has drifted from the
  textbook odds.
- **Board builder** — lay out your board hex by hex, then see which settlement spots are
  actually producing given the rolls so far.

## Running it

It's a single self-contained HTML file with no build step and no dependencies — open
[`index.html`](index.html) in a browser, or use the live link above.
